# 新设备必须通过桌面批准的短时配对挑战

新增手机或桌面不能凭扫码、短码或恢复密钥直接取得长期授权：已授权桌面生成一次性、2 分钟有效的 Pairing Challenge，新设备提交后两端显示匹配校验码，用户必须在现有桌面明确批准，控制面随后才签发该设备独立的 Device Credential。每个桌面同一时间只有一个有效挑战，新挑战使旧挑战失效，成功、拒绝、取消、超时或 5 次错误短码尝试都会终止挑战；二维码为主、人工短码为备用，两种入口都必须经过同一桌面确认。V1 的有效授权上限为 3 台 Desktop Instance 和 5 台 Mobile Device；达到相应上限时，必须先撤销一台同类设备，不能自动替换或挤掉既有设备。当前只设计一个 Preferred Desktop 处理呼叫，不把“最多 3 台桌面已授权”解释成多桌面并发或自动改呼。日常新增桌面必须由现有桌面批准，Owner Recovery Key 只用于所有授权桌面均不可用时的灾难恢复。
